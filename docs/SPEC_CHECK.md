# SPEC_CHECK — 기획서 문장별 대조

`01_기획서.md`의 기능 문장마다 구매자·판매자가 **화면에서 끝까지 갈 수 있는지**, 서버·로직이 어디인지, 무엇으로 확인했는지 적는다.
기준: 서버 테스트만 있고 화면 경로가 없으면 완료로 치지 않는다. 2026-11-03 기준(v4: 판매자 쉬기·기본값·지금 나가요·노출 수, 폰 화면 개편 반영).

상태: ✅ 화면까지 구현 · ↪ 확인된 다른 방법으로 대체 · 🧪 시연용(실서비스 전 교체) · ⏳ 실제 기기·에뮬레이터 확인 미실행 · ✖ 안 함(기획서 7-4·11-4)

화면 약칭: **차** = 차량 화면(`apps/car-web`), **판폰** = 판매자 폰(`apps/seller-web`), **구폰** = 구매자 폰(`apps/buyer-web`), **E2E** = `npm run e2e`, **브리지** = `npm run e2e:bridge`
